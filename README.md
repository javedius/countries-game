# Countries Game

Это браузерная мини-игра на `HTML + CSS + JavaScript`, собранная через `Vite`.

В центре экрана находится круглая арена с вращающимся кольцом. Кольцо состоит из `36` секций, из которых `4` секции отсутствуют. Эти пустые секции работают как выход: через них страны могут вылетать с арены.

На арене появляются шарики со странами. Каждый шарик:
- представляет отдельную страну;
- двигается с постоянной скоростью;
- сталкивается с другими шариками;
- меняет направление при ударах о борт;
- может вылететь через пустой сектор кольца.

Побеждает последняя страна, оставшаяся внутри круга.

## Как работает игра

Логика раунда такая:

1. В начале создаётся список стран для текущего раунда.
2. Порядок появления стран перемешивается случайным образом.
3. Страны появляются по одной с задержкой, которая задаётся в `CONFIG`.
4. Кольцо постоянно вращается, а пустой сектор двигается вместе с ним.
5. Когда шарик доходит до пустого сектора, он начинает выходить наружу и больше не отскакивает обратно внутрь.
6. Когда на арене остаётся одна страна, она объявляется победителем.
7. Через несколько секунд начинается следующий раунд.

## Озвучка

В игре есть браузерная озвучка через `speechSynthesis`.

Сейчас озвучиваются:
- `5 countries left`
- `{country} is the winner`

Важно:
- в мобильных и некоторых десктопных браузерах озвучка начинает работать только после первого тапа или клика по странице;
- голос зависит от системы и браузера пользователя.

## Настройки

Основные настройки находятся в начале файла:

[main.js](/Users/javedius/Desktop/countries-game/main.js)

Главный объект:

```js
const CONFIG = {
  totalSections: 36,
  gapSectionCount: 4,
  itemSpawnMs: 100,
  ringRotationSpeed: 0.6,
  itemRepulsionForce: 1,
  wallRepulsionForce: 1000,
  itemSpeed: 240,
  forcedWinnerIso: "",
  forcedWinnerBias: 28,
};
```

Что означают параметры:

- `totalSections` — общее количество секций кольца.
- `gapSectionCount` — количество пустых секций, через которые можно вылететь.
- `itemSpawnMs` — интервал появления новых стран.
- `ringRotationSpeed` — скорость вращения кольца.
- `itemRepulsionForce` — сила изменения направления при столкновении стран.
- `wallRepulsionForce` — сила изменения направления при ударе о борт.
- `itemSpeed` — постоянная скорость движения активных шаров.
- `forcedWinnerIso` — если строка пустая, игра честная; если указан ISO-код страны, игра ведёт к победе этой страны.
- `forcedWinnerBias` — сила влияния режима предопределённого победителя.

Также в `main.js` есть внутренние константы физики и геометрии арены:
- центр круга;
- радиус арены;
- радиус шаров;
- гравитация для выбывших шаров;
- высота, на которой оседают выбывшие шары.

## Запуск проекта

Установка зависимостей:

```bash
npm install
```

Запуск в режиме разработки:

```bash
npm run dev
```

После этого открой адрес, который покажет `Vite`.

Сборка production-версии:

```bash
npm run build
```

Предпросмотр production-сборки:

```bash
npm run preview
```
